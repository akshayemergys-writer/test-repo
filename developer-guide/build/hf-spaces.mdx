[Hugging Face Spaces](https://huggingface.co/sambanovasystems) provide interactive web applications for models, datasets, and demos. SambaNova examples include a trip planner and an automatic web-search assistant.

To build your own demo, use the [Gradio integration](/developer-guide/build/community) with a server-side API key. Do not expose the key in browser code or commit it to the Space repository.

## Practical use case: share a model demo

A developer can package a SambaNova-powered trip planner or document assistant in a Gradio Space, keep the API key in Space secrets, and give reviewers a browser-based demo.
