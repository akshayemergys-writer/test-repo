Specialized subagents include Coding, Data Science, Deep Research, and Financial Analysis. They are designed for focused tasks and return structured reports or artifacts depending on the endpoint.

Select the narrowest capable agent, provide explicit output requirements, and retain the request ID for troubleshooting.

## Practical use case: quarterly review

Send financial figures to the Financial Analysis agent, source documents to the Deep Research agent, and spreadsheets to the Data Science agent, then combine their reports in your application.
