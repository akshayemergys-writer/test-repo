## Topic

Learn how to install Python, verify your installation, and use the terminal to run Python programs.

## Commands to implement it

```bash
# Check Python version
python --version
python3 --version

# Run the Python interpreter
python
# or
python3

# Exit the Python interpreter
exit()
```

On macOS or Linux:

```bash
curl https://www.python.org/ftp/python/3.12.0/python-3.12.0-macos11.tar.xz -o python.tar.xz
tar -xf python.tar.xz
```

On Windows, download the installer from [python.org](https://www.python.org/downloads/).
