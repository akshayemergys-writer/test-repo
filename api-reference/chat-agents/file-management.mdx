Use the file-management endpoint to download artifacts generated by agent APIs. Requests use bearer authentication and files are scoped to the authenticated user.

Treat returned file IDs as sensitive references and verify ownership before exposing downloads to end users.

## Practical use case: generated report download

After a research agent creates a PDF or spreadsheet, your application can show a download button that requests the artifact only after verifying the authenticated user's ownership.
