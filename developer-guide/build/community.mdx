Visit the [SambaNova Developer Community](https://community.sambanova.ai/) for questions, examples, announcements, and peer discussion.

When asking for help, include the product, model ID, endpoint, SDK version, request shape, and the request ID from the error response. Never include API keys or sensitive prompt data.

## Practical use case: troubleshoot a failed request

When an integration returns an unexpected error, a developer can share the model ID, endpoint, SDK version, sanitized request shape, and request ID with the community without exposing credentials.
