## Overview

Dataflow Architecture is the execution model behind SambaNova's AI systems. It organizes computation and movement of data around the workload so models can run efficiently on RDU hardware.

## How it is used

- Map model operations to the dataflow execution model.
- Use the memory hierarchy and compute resources efficiently.
- Deploy the resulting workload through SambaNova platform software.
- Measure latency, throughput, and energy efficiency for the target model.

<Note>
  Architecture concepts explain how SambaNova products work together; they are not a separate end-user service or API.
</Note>
