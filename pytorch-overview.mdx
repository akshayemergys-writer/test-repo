## Topic

PyTorch is a deep learning framework. Understanding its basics helps you read and write deep learning code.

## What is PyTorch?

PyTorch is a library for:
- Creating neural networks
- Training models on large datasets
- Running on GPUs for speed
- Research and production

## Tensors: The core data structure

A **tensor** is PyTorch's way of storing data. It's like a NumPy array but GPU-optimized.

```python
import torch

# Create tensors
scalar = torch.tensor(5)                    # Single value
vector = torch.tensor([1, 2, 3])            # 1D array
matrix = torch.tensor([[1, 2], [3, 4]])     # 2D array
tensor_3d = torch.randn(2, 3, 4)            # 3D (batch_size, height, width)
```

## Basic operations

```python
x = torch.tensor([1, 2, 3])
y = torch.tensor([4, 5, 6])

# Element-wise operations
z = x + y         # [5, 7, 9]
z = x * y         # [4, 10, 18]

# Matrix multiplication
a = torch.randn(2, 3)
b = torch.randn(3, 4)
c = torch.matmul(a, b)  # (2, 4)
```

## GPU support

```python
# Move tensor to GPU if available
device = torch.device(\"cuda\" if torch.cuda.is_available() else \"cpu\")
x = torch.tensor([1, 2, 3]).to(device)

# Or create on GPU directly
y = torch.randn(3, requires_grad=True, device=device)
```

GPU makes training neural networks much faster (10-100x speedup).

## Why the ML community uses PyTorch

1. **Easy to learn**: Pythonic syntax, intuitive API
2. **Dynamic computation graphs**: Debug code line-by-line like normal Python
3. **GPU support**: Seamless CUDA/GPU acceleration
4. **Large ecosystem**: Lots of libraries built on top
5. **Research-friendly**: Widely used in academia

## PyTorch vs TensorFlow

| Aspect | PyTorch | TensorFlow |
|--------|---------|-----------|
| Ease of learning | Easier | Steeper learning curve |
| Debugging | Easier (dynamic) | Harder (static graphs) |
| Production | Good | Excellent |
| Research | Dominant | Growing |
| Industry | Increasing | Established |

## How it relates to Hugging Face

Hugging Face `transformers` library builds on PyTorch:

```python
from transformers import AutoModel
import torch

model = AutoModel.from_pretrained(\"bert-base-uncased\")
# This model is a PyTorch nn.Module

# You can treat it like any PyTorch model:
inputs = torch.tensor([[101, 7592, 2088, 102]])
outputs = model(inputs)
```

So learning PyTorch basics prepares you to understand Hugging Face models and training scripts.

<Note>
  You don't need to master PyTorch to use Hugging Face models. But understanding tensors and basic operations helps you debug and customize.
</Note>
