## Git getting started

- Configuring Git with `git config` for your username and email
- Initializing a repository with `git init`
- Cloning a repository with `git clone`

## Git basics

- Staging files with `git add`
- Committing changes with `git commit`
- Viewing status with `git status`
- Viewing history with `git log`

## Git branching

- Creating and switching branches with `git branch` and `git checkout`
- Merging branches with `git merge`
- Deleting branches
- Viewing all branches

## Git and GitHub

- Creating a GitHub account and repository
- Connecting a local repository to GitHub with `git remote`
- Pushing changes with `git push`
- Pulling changes with `git pull`
- Fetching changes with `git fetch`

## Git undo and reset

- Undoing changes with `git revert`
- Resetting commits with `git reset`
- Amending the last commit with `git commit --amend`

## GitHub features

- Pull requests
- Forking a repository
- Issues and project boards
- The `.gitignore` file
