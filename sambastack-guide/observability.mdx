SambaStack observability includes OpenSearch log storage and search, Fluent Bit log forwarding, Prometheus and Grafana monitoring, metrics, and logs.

Track model health, request errors, latency, throughput, resource utilization, and deployment events. Redact credentials and sensitive prompt data before forwarding logs.

## Practical use case: diagnose rising latency

An operator can correlate request latency metrics with model logs, node utilization, and deployment events to determine whether a slowdown comes from traffic, capacity, or a model-service issue.
