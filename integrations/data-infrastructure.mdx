Infrastructure integrations include AWS Marketplace and AWS PrivateLink. Orchestration integrations include DataRobot and Docker Compose for Agents.

Vector and search integrations include Mem0, Milvus, and Neo4j. Use these components to build memory layers, semantic retrieval, graph retrieval, and governed production workflows around SambaNova inference.

## Practical use case: private enterprise search

An enterprise can route requests through AWS PrivateLink, orchestrate services with Docker Compose, and store searchable document vectors in Milvus while keeping the inference path private.
