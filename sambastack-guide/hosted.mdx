In the hosted model, SambaNova provides and manages the data-center infrastructure and Kubernetes environment. Your team configures the AI services, including model selection, users, and user groups.

Start by receiving the deployment URL and administrator credentials, configure authentication, select available model bundles, and test an inference request through the deployment endpoint.

## Practical use case: managed production inference

An enterprise can use hosted SambaStack to launch dedicated model services without running the underlying Kubernetes cluster, while retaining control of model selection, users, groups, and application access.
