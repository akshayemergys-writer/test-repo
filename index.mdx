## Demo roadmap

<Steps>
  <Step title="Package the application">
    Start with [Container fundamentals](/container-fundamentals) and learn how Docker turns application code into a repeatable image.
  </Step>
  <Step title="Coordinate workloads">
    Move through [Container orchestration](/container-orchestration) to understand scaling, traffic distribution, and recovery.
  </Step>
  <Step title="Understand the cluster">
    Use [Kubernetes overview](/kubernetes-overview) and [Kubernetes architecture](/kubernetes-architecture) to see where control-plane decisions happen.
  </Step>
  <Step title="Operate an application">
    Learn Pods, Deployments, Services, configuration, storage, scaling, and security through the pages below.
  </Step>
</Steps>
