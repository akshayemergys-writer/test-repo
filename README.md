# SambaNova Offerings Documentation

Documentation for SambaNova's cloud, managed, enterprise, hardware, and architecture offerings, built with Mintlify.

## Preview locally

Install the [Mintlify CLI](https://www.npmjs.com/package/mint):

```bash
npm i -g mint
```

Start the preview from the project root, where `docs.json` is located:

```bash
mint dev
```

Open `http://localhost:3000` in your browser.

## Publishing changes

Push changes to the configured deployment branch to publish the documentation through Mintlify.

## Need help?

### Troubleshooting

- Run `mint update` if the CLI is outdated.
- Make sure you run `mint dev` from the directory containing `docs.json`.
