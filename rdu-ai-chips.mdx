## Overview

The Reconfigurable Dataflow Unit (RDU) is SambaNova's purpose-built processor architecture for AI workloads.

## How it is used

- Select a SambaNova system that includes RDU hardware.
- Deploy supported models through SambaStack or SambaCloud.
- Measure throughput, latency, and energy efficiency for the target workload.
- Scale across the available infrastructure configuration.

<Note>
  An RDU is hardware infrastructure rather than a standalone application API. Applications access it through SambaNova software and platform layers.
</Note>
