Evaluation and monitoring integrations include Inspect AI, LM Evaluation Harness, and Weave.

Use evaluation suites to compare models and prompts against repeatable datasets. Use tracing and monitoring to inspect latency, token usage, tool calls, errors, and production regressions without logging sensitive prompts unnecessarily.

## Practical use case: release a safer model update

Before changing models, a team can run a fixed support-question dataset through Inspect AI or LM Evaluation Harness, compare quality and latency, and use Weave traces to investigate regressions.
