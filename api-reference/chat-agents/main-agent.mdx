The Main Agent coordinates specialized capabilities such as coding, financial analysis, deep research, and data science. The non-interactive endpoint accepts a prompt and returns a completed response.

Use the interactive Main Agent endpoint when your application needs persistent thread context or approval between steps.

## Practical use case: executive briefing

An executive assistant can submit a request to summarize market updates, let the Main Agent coordinate research and analysis, and return one briefing instead of exposing every internal subtask to the user.
