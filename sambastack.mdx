## Overview

SambaStack combines SambaNova hardware and software into a dedicated AI inference platform that can run on-premises or in a dedicated cloud environment.

## How it is used

- Select an on-premises or hosted deployment model.
- Size infrastructure for the required models and throughput.
- Configure supported model bundles and workloads.
- Connect applications through the platform's inference interfaces.

<Note>
  SambaStack is a full-stack offering combining purpose-built hardware, software, model support, and deployment options.
</Note>
