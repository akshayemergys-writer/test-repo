## Learning path

<CardGroup cols={2}>
  <Card title="Container fundamentals" icon="cube" href="/container-fundamentals">
    Learn what containers are and how Docker runs them.
  </Card>
  <Card title="Container orchestration" icon="sitemap" href="/container-orchestration">
    Understand why teams use orchestration and what it provides.
  </Card>
  <Card title="Kubernetes overview" icon="dharmachakra" href="/kubernetes-overview">
    Learn Kubernetes concepts, use cases, and its relationship with Docker.
  </Card>
  <Card title="Kubernetes architecture" icon="diagram-project" href="/kubernetes-architecture">
    Explore control plane and worker node components.
  </Card>
  <Card title="Pods" icon="boxes-stacked" href="/pods">
    Deploy and understand Kubernetes' smallest workload unit.
  </Card>
  <Card title="ReplicaSets" icon="copy" href="/replicasets">
    Maintain the desired number of running pod replicas.
  </Card>
  <Card title="Deployments" icon="rocket" href="/deployments">
    Manage rolling updates, rollbacks, and application releases.
  </Card>
  <Card title="Services and networking" icon="network-wired" href="/services-networking">
    Expose workloads and connect services inside and outside a cluster.
  </Card>
  <Card title="Configuration and labels" icon="file-code" href="/configuration-yaml-labels">
    Write manifests and organize resources with labels and selectors.
  </Card>
  <Card title="Storage" icon="hard-drive" href="/storage-pv-pvc">
    Persist application data with volumes, PVs, and PVCs.
  </Card>
  <Card title="Scaling and updates" icon="arrows-up-down" href="/scaling-updates">

  </Card>
  <Card title="Security" icon="shield-halved" href="/security-rbac-secrets">
    Control access with RBAC, namespaces, Secrets, and ConfigMaps.
  </Card>
