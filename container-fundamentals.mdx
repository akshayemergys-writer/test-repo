## Topic

Understand what containers are, how they differ from virtual machines, and how Docker builds and runs them.

## Commands to implement it

```bash
docker version
docker info
docker pull nginx:latest
docker images
docker run -d --name web -p 8080:80 nginx:latest
docker ps
docker stop web
docker rm web
```

Create a basic `Dockerfile`:

```dockerfile
FROM nginx:latest
COPY index.html /usr/share/nginx/html/index.html
```

Build and run it:

```bash
docker build -t my-web:1.0 .
docker run -d --name my-web -p 8080:80 my-web:1.0
```

## Output

```text
CONTAINER ID   IMAGE         COMMAND                  STATUS         PORTS                  NAMES
7a1b2c3d4e5f   nginx:latest  "/docker-entrypoint…"   Up 10 seconds  0.0.0.0:8080->80/tcp   web
```

<Note>
  Containers share the host kernel, while virtual machines include a complete guest operating system. Docker images are immutable templates; containers are running instances of images.
</Note>
