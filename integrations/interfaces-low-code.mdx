LLM interfaces and gateways include Gradio and Open WebUI. Low-code platforms include Dify, Flowise, Langflow, Make, and n8n.

These tools can provide chat interfaces, workflow composition, retrieval, tool calling, and API publishing without requiring every application layer to be written from scratch.

Use a server-side connection wherever possible and validate the model and endpoint options exposed by the platform.

## Practical use case: internal knowledge chatbot

A team can connect Open WebUI or Dify to SambaNova, configure a private knowledge source, and publish an internal chatbot without building the complete chat interface and workflow editor from scratch.
