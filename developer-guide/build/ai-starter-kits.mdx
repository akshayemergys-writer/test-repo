[AI Starter Kits](https://github.com/sambanova/ai-starter-kit) are open-source Python examples that demonstrate reusable application patterns.

Examples include quickstart, enterprise knowledge retrieval, multimodal retrieval, benchmarking, function calling, search assistants, financial assistants, agents, video analysis, and voice assistants. Get an API key before running a kit, then follow each kit's README for dependencies and configuration.

## Practical use case: prototype an enterprise search assistant

A team can start with the enterprise knowledge retrieval kit, replace its sample documents with internal policies, and use the working retrieval flow as the foundation for a production prototype.
