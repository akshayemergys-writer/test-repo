## Topic

NumPy and Pandas are the foundation of data science in Python. NumPy handles numerical arrays; Pandas handles tabular data.

## NumPy basics

```python
import numpy as np

# Create arrays
arr = np.array([1, 2, 3, 4, 5])
zeros = np.zeros((3, 3))  # 3x3 matrix of zeros
ones = np.ones((2, 4))    # 2x4 matrix of ones
arange = np.arange(10)    # [0, 1, 2, ..., 9]

# Array operations
arr = np.array([1, 2, 3, 4])
print(arr * 2)     # [2, 4, 6, 8]
print(arr + 10)    # [11, 12, 13, 14]
print(np.mean(arr))  # 2.5
print(np.sum(arr))   # 10
```

## Pandas DataFrames

```python
import pandas as pd

# Create a DataFrame
data = {
    "name": ["Alice", "Bob", "Charlie"],
    "age": [30, 25, 35],
    "city": ["New York", "London", "Paris"]
}
df = pd.DataFrame(data)

# Read from CSV
df = pd.read_csv("data.csv")

# View data
print(df.head())  # First 5 rows
print(df.describe())  # Statistical summary
print(df.shape)   # (rows, columns)
```

## DataFrame operations

```python
# Select a column
names = df["name"]
ages = df[["name", "age"]]  # Multiple columns

# Filter rows
over_30 = df[df["age"] > 30]

# Access by position
first_row = df.iloc[0]  # First row
cell = df.iloc[0, 1]    # First row, second column

# Access by label
alice = df.loc[0]  # Row with index 0
age = df.loc[0, "age"]

# Group by
age_groups = df.groupby("city")["age"].mean()

# Add a column
df["age_group"] = df["age"].apply(lambda x: "Adult" if x >= 18 else "Minor")
```

## Common DataFrame methods

| Method | Purpose |
|--------|---------|
| `.head()` | First n rows |
| `.tail()` | Last n rows |
| `.describe()` | Statistical summary |
| `.groupby()` | Group by column |
| `.sort_values()` | Sort by column |
| `.drop()` | Remove columns or rows |
| `.fillna()` | Fill missing values |
| `.isnull()` | Find missing values |

<Note>
  NumPy is efficient for mathematical operations. Pandas is better for tabular data with mixed types (strings, numbers, dates).
</Note>
