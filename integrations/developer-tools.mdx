The Developer Tools category includes coding assistants such as Cline, Cursor, Continue, Claude Code, Codex, OpenHands, OpenCode, Qwen Code CLI, and VS Code AI Toolkit.

Tool and browser integrations include Browser Use, Composio, Exa, FastMCP, Google Workspace, Instructor, and Linkup. Configure each tool with a SambaNova-compatible base URL, API key, and supported model ID.

<Note>
  Keep API keys in the tool's server-side environment or secret manager. Do not place credentials in editor settings that are shared with a repository.
</Note>

## Practical use case: coding assistant in the editor

A developer can configure Cline, Cursor, or VS Code AI Toolkit with a SambaNova base URL and model ID, then use the assistant for code explanation and review while keeping the API key in the editor's secure environment.
