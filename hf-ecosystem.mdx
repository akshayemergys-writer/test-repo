## Topic

Hugging Face is a central hub for pre-trained models and tools. Understanding its components helps you leverage state-of-the-art NLP and vision models.

## Core components

### Model Hub

A repository hosting thousands of pre-trained models shared by the community and organizations.

- Visit [huggingface.co/models](https://huggingface.co/models)
- Browse by task: text-classification, summarization, object-detection, etc.
- Each model has a model card with documentation

### Model Cards

Detailed documentation for each model. Includes:

- **Model description**: What it does, training data, capabilities
- **Intended use**: Recommended use cases
- **Limitations**: Known biases, performance gaps
- **Training details**: Data, parameters, metrics
- **Evaluation results**: Benchmark scores
- **Responsible AI**: Ethical considerations

Example: Model card for `bert-base-uncased` shows it was trained on English Wikipedia and BookCorpus.

### Transformers Library

Python library for loading and using pre-trained models:

```python
from transformers import AutoTokenizer, AutoModel

model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name)
```

### Spaces

Interactive apps and demos powered by Hugging Face models. Share your ML projects as live web apps.

Example: Spaces showcase image generation, text summarization, question answering, etc.

### Inference API

REST API to run models without downloading them. Perfect for quick experiments or production if you don't want to manage infrastructure.

```python
import requests

API_URL = "https://api-inference.huggingface.co/models/bert-base-uncased"
headers = {"Authorization": f"Bearer {HF_API_KEY}"}

response = requests.post(API_URL, headers=headers, json={
    "inputs": "This is a test sentence."
})
```

## Finding and loading models

1. Go to [huggingface.co/models](https://huggingface.co/models)
2. Search for task or model name
3. Click on model to see details and code example
4. Use model ID (e.g., `distilbert-base-uncased-finetuned-sst-2-english`) with `transformers` library

```python
from transformers import pipeline

# Simple API: pipeline handles model loading
classifier = pipeline("sentiment-analysis")
results = classifier("I love this!")  # [{'label': 'POSITIVE', 'score': 0.999...}]
```

<Note>
  Hugging Face models are versioned. Pin specific versions in production for reproducibility.
</Note>
