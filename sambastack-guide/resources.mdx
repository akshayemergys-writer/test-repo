SambaStack resources include pod references, SambaRack installation guidance, rack component and cabling references, third-party components, SBOM and security reports, and the SambaStack glossary.

Use the resource that matches the physical, platform, or software layer you are troubleshooting.

## Practical use case: resolve a deployment incident

An operator can use pod references for Kubernetes symptoms, hardware references for rack or cabling issues, and SBOM or security reports when investigating a component vulnerability.
