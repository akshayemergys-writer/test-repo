The SambaNova Developer Guide explains how to connect applications to SambaCloud and SambaStack, choose models, and build production AI workflows.

SambaCloud is SambaNova's hosted API service. SambaStack is a deployment operated in your own environment. Both use related technologies, but available models, URLs, authentication, and administration responsibilities can differ.

## What you can build

- Chat and text-generation applications
- OpenAI- or Anthropic-compatible integrations
- Structured JSON and function-calling workflows
- Vision, video, audio, embeddings, and text-to-speech experiences
- Retrieval-augmented generation (RAG) and tool-using agents
- Applications using reasoning models or custom chat templates

## Product coverage

Use the product that matches your operating model:

| Product | Best suited for | Main responsibility |
| --- | --- | --- |
| SambaCloud | Hosted development and inference | SambaNova operates the service; you call the API |
| SambaStack | Private deployment in your environment | Your organization and administrator operate the deployment |

<Note>
  Model availability, limits, endpoints, and compatibility can change. Confirm live values in the official SambaNova documentation before production deployment.
</Note>

## Practical use case: plan a new AI application

A team can start with the API keys and Quickstart pages, select a production model, choose Chat Completions or Responses, and then add retrieval, tools, or multimodal input only where the application needs them.
