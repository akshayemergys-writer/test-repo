## Topic

A ReplicaSet keeps a specified number of matching Pods running. It creates replacements when Pods fail or are removed.

The command examples use `nginx:latest`, a Docker image for the Nginx web server. `latest` is an image tag, meaning a human-readable label for an image version. In production, use a specific version such as `nginx:1.27` so the workload does not change unexpectedly.

## Commands to implement it

```bash
kubectl create deployment web --image=nginx:latest
kubectl get replicasets
kubectl scale deployment web --replicas=3
kubectl get pods -l app=web
kubectl describe replicaset
```

## Output

```text
NAME              DESIRED   CURRENT   READY   AGE
web-7d4f7c8d9f    3         3         3       1m
```

<Note>
  Deployments normally create and manage ReplicaSets for you. Create a ReplicaSet directly only when you need lower-level control.
</Note>
