LLM framework integrations include AI Suite, Haystack, Hugging Face, LangChain, LiteLLM, LlamaIndex, Llama Stack, OpenRouter BYOK, Oumi, and Vercel.

Agent orchestration integrations include ADK, Agent Zero, Agno, AutoGen, Camel AI, CrewAI, LangGraph, OpenClaw, OpenWorker, and Semantic Kernel.

Most integrations use the OpenAI-compatible endpoint. Configure the provider base URL and API key, then select a SambaNova model from the supported model list.

## Practical use case: RAG with an orchestration framework

A team can use LangChain or LlamaIndex to load documents, retrieve relevant passages, and pass them to a SambaNova model while keeping provider-specific connection code in one configuration layer.
