## Topic

How you phrase requests to language models dramatically affects results. Prompt engineering is the practice of crafting effective prompts.

## Prompt anatomy

### System prompt

Context and instructions for the model's behavior (optional but powerful).

```
System: "You are a helpful assistant that speaks like a pirate."
User: "How do I bake cookies?"
Assistant: "Ahoy, me hearty! 'Tis a simple task..."
```

### User prompt

The actual question or request.

```
User: "What is machine learning?"
```

## Prompting techniques

### Zero-shot prompting

Ask the model without examples. The model uses its pre-training knowledge.

```
Prompt: "Classify the sentiment: 'This product is terrible.'"
Model: "Negative"
```

**Pros**: Simple, fast.
**Cons**: Less control, may miss nuances.

### Few-shot prompting

Provide examples before the actual request.

```
Prompt:
"Here are examples:
- 'Great movie!' → Positive
- 'I hated it.' → Negative
- 'It was okay.' → Neutral

Classify: 'This is amazing!'"

Model: "Positive"
```

**Pros**: Better control, more consistent.
**Cons**: Uses more tokens, may affect output style.

### Chain-of-thought prompting

Ask the model to "think step-by-step" before answering.

```
Prompt: "A store has 50 apples. They sell 30. How many are left? 
         Think step-by-step."

Model: 
"Step 1: Start with 50 apples
 Step 2: Subtract 30 that were sold
 Step 3: 50 - 30 = 20
 Answer: 20 apples remain"
```

**Pros**: Better reasoning, fewer errors on complex tasks.
**Cons**: Longer responses, more tokens.

## Key prompting parameters

**Temperature**: Controls randomness (0 = deterministic, 1+ = creative).

```
Temperature 0: Same response every time
Temperature 0.7: Balanced (default for chat)
Temperature 1+: Very random/creative
```

**Max tokens**: Maximum response length.

```
max_tokens=50 → Short response
max_tokens=500 → Longer response
```

**Top-p (nucleus sampling)**: Keep only top-p probability mass.

```
top_p=0.9 → Only consider tokens with 90% cumulative probability
top_p=0.5 → More focused, less diverse
```

## Prompt templates for reproducibility

Store prompt templates as files or in code:

```python
CLASSIFICATION_TEMPLATE = """
You are a sentiment classifier.
Classify the following text as positive, negative, or neutral.

Text: {text}

Classification:
"""

prompt = CLASSIFICATION_TEMPLATE.format(text="This is great!")
```

## Best practices

1. **Be specific**: "Summarize this article" → "Summarize this article in 2-3 sentences for a 10-year-old."
2. **Provide context**: Tell the model its role ("You are a Python expert...")
3. **Use examples**: Few-shot prompting improves consistency
4. **Test variations**: Small prompt changes can have big impacts
5. **Document prompts**: Keep track of what works for reproducibility

<Tip>
  Prompting is an art and science. Experiment, iterate, and measure results.
</Tip>
