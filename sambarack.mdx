## Overview

SambaRack is SambaNova's rack-scale infrastructure for running large AI inference workloads with purpose-built RDU hardware.

## How it is used

- Plan rack capacity, power, cooling, and network requirements.
- Select the required model bundles and deployment configuration.
- Connect the rack to surrounding data-center services.
- Serve inference workloads through the configured SambaStack software layer.

<Note>
  SambaNova's public materials describe SambaRack SN50 as rack-scale infrastructure designed for high-throughput inference.
</Note>
