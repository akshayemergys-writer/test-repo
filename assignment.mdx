## Topic

Build and document a small Linux administration workflow that demonstrates the skills from every topic page.

## Commands to implement it

```bash
mkdir -p ~/linux-assessment/{data,backup}
touch ~/linux-assessment/data/report.txt
chmod 640 ~/linux-assessment/data/report.txt
cp ~/linux-assessment/data/report.txt ~/linux-assessment/backup/
tar -czf ~/linux-assessment.tar.gz ~/linux-assessment
df -h ~/linux-assessment
```

Also record the results of checking a service, a route, a log entry, and the current user.
