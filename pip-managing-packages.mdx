## Topic

`pip` is Python's package manager. It downloads and installs packages from the Python Package Index (PyPI).

## Commands to implement it

```bash
# Install a package
pip install requests

# Install a specific version
pip install requests==2.31.0

# List installed packages
pip list

# Show information about a package
pip show requests

# Uninstall a package
pip uninstall requests

# Upgrade a package
pip install --upgrade requests
```

## Understanding package versions

- **`requests`**: Installs the latest version.
- **`requests==2.31.0`**: Installs exactly version 2.31.0.
- **`requests>=2.30.0`**: Installs 2.30.0 or newer.
- **`requests>=2.30.0,<3.0.0`**: Installs 2.30.0 up to (but not including) 3.0.0.

## PyPI (Python Package Index)

PyPI is the central repository where developers publish Python packages. You can search packages at [pypi.org](https://pypi.org).

<Note>
  Always check the package documentation and community feedback before installing. Popular packages like `requests`, `numpy`, and `pandas` are well-maintained and widely trusted.
</Note>
