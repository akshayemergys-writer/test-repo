Learn how to identify resource usage and performance pressure on a Linux system.

## Topic

Monitor CPU, memory, processes, disk space, and network activity to identify resource pressure.

## Commands to implement it

```bash
top
free -h
uptime
df -h
ip -s link
```

Install `htop` with your distribution's package manager, then run it for an interactive process view:

```bash
htop
```

Press `q` to exit `top` or `htop`.

## Output

```text
							total        used        free      shared  buff/cache   available
Mem:           3.8Gi       1.2Gi       1.6Gi       120Mi       1.0Gi       2.4Gi
Swap:          2.0Gi          0B       2.0Gi
```

<Note>
	A high load average does not always mean high CPU usage. Compare it with the number of CPU cores and inspect memory and I/O as well.
</Note>
