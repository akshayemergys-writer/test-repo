## Topic

Never hardcode API keys, passwords, or secrets in your code. Use environment variables to keep them safe.

## Using environment variables

```python
import os

# Read from environment
api_key = os.environ.get("API_KEY")
database_url = os.environ.get("DATABASE_URL", "default_value")

print(api_key)
```

Set environment variables in your terminal:

```bash
# On macOS/Linux
export API_KEY="your-secret-key"
export DATABASE_URL="postgresql://localhost:5432/mydb"

# On Windows PowerShell
$env:API_KEY = "your-secret-key"
```

## Using .env files with python-dotenv

Create a `.env` file in your project root:

```
API_KEY=your-secret-key-here
DATABASE_URL=postgresql://localhost:5432/mydb
DEBUG=True
ENVIRONMENT=development
```

Install `python-dotenv`:

```bash
pip install python-dotenv
```

Load it in your code:

```python
from dotenv import load_dotenv
import os

# Load .env file
load_dotenv()

api_key = os.environ.get("API_KEY")
debug = os.environ.get("DEBUG") == "True"
```

## Best practices

- Add `.env` to `.gitignore` to avoid committing secrets.
- Use `.env.example` to document what variables are needed:

```
# .env.example
API_KEY=your-api-key-here
DATABASE_URL=your-database-url-here
DEBUG=False
```

<Warning>
  Never commit `.env` files. Leaked keys can be exploited to compromise your systems.
</Warning>
