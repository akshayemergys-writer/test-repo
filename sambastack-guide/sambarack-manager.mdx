SambaRack Manager provides rack administration workflows including initial setup, device credentials, node and group administration, power operations, firmware updates, inventory schema, and command reference.

Use maintenance windows for firmware and power actions, and keep inventory files and device credentials under controlled access.

## Practical use case: inventory a new rack

After installation, an administrator can use SambaRack Manager to load the inventory, register nodes, create groups, verify device credentials, and confirm rack health before deployment.
