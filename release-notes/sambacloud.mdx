SambaCloud release notes cover API enhancements, newly available models, performance improvements, rate-limit changes, and infrastructure updates.

Before production changes, review model availability and deprecation notices in the [Developer Guide models section](/developer-guide/models). Test endpoint and SDK changes against a staging key where possible.

## Practical use case: prepare a model change

Before switching a production assistant to a newly released model, compare its output and latency against the current model and review any related rate-limit or deprecation notices.
